Website Name: MovieHub

live link: https://ph-assignment10.netlify.app/

Five feature of this website:  

    1. Dynamic Movie Management:
    Users can explore, add, update, and delete movies with a user-friendly interface.
    Includes functionalities for managing user-favorite movies seamlessly.

    2. Authentication System:
    Provides secure user login and registration using email/password.
    Social login via Google for a fast and seamless experience.

    3. Advanced Search and Filtering:
    Search movies by title to quickly locate favorites or explore content.
    Sort featured movies by rating to highlight the best choices.

    4. Responsive Design:
    Optimized for desktop, tablet, and mobile devices for a seamless experience across all platforms.
    Includes light/dark mode toggle for user preference.

    5. Enhanced User Experience:
    Meaningful toasts and SweetAlert notifications for every action.
    Interactive movie details page with "Add to Favorites" and "Update/Delete" options.
